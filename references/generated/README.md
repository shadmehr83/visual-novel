# Generated story backgrounds

`first-match-departure-original.png` is the unmodified generated background for **After the café**. The protected café image supplied the painting style and palette reference; it was not modified. The new composition looks down onto wet paving, café-light reflections and rain ripples, leaving the right side quieter for the phone overlay.

`first-match-departure.webp` is the same image encoded at quality 90, with unchanged 1672 × 941 dimensions, for a compact embedded project asset. The scene has no added window masks, lamp zones or cloth movement from another picture; rain ripples and reflections are painted into this background.

The portable project embeds the WebP as `first-match-departure`. Both the engine downloads and GitHub snapshot include it.

## Stillframe 2.4

`first-match-monitor.webp` is an original generated desk close-up using the existing bedroom as its style reference. `first-match-chat.webp`, `first-match-feed.webp` and `first-match-settings.webp` are three original app icons. They were generated specifically for this project, then encoded as WebP at unchanged dimensions for compact portable builds. Source generated PNGs remain in the execution workspace; the WebPs are committed and embedded in the portable project.

Stillframe 2.5 adds `first-match-window.webp`, an original generated front-facing rainy window illustration using the bedroom as its style reference, encoded at unchanged dimensions. Each window pane has an authored rain/glass mask in the project. The monitor view has separately placed masks above and beside the screen.

## Weather app icon

`weather-app-icon-original.png` is the original generated artwork for the fictional Weather app, matching the existing painterly copper/plum phone icons. The source remains unmodified. The app uses a small 96×96 WebP delivery copy embedded in `src/weatherIcon.ts` and the published project's artwork library. A chosen custom Weather icon overrides this default.

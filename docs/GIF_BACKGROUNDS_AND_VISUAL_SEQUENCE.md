# GIF backgrounds and visual background sequences

Open **Background → Upload GIF background** to use an animation as the main background. The normal background file picker accepts PNG, JPEG, WebP and GIF. GIF bytes stay in JSON exports, offline editor and playable exports. Playback uses the browser's GIF loop; this is not a frame-accurate video timeline.

In **Scenes advanced**, select a scene to expand its **Background sequence**. Cards show the actual artwork, animation/still labels, transition style/duration and dialogue trigger buttons. The arrows represent changes of view, not an automatic slideshow. Choose **Cue this view at dialogue** on a card to assign it; click an existing dialogue cue to edit that line. **Add still / GIF sub-scene** imports a new view at your chosen dialogue, defaulting to a smooth crossfade. The original dialogue editor's **This dialogue view** selector remains available. Dialogue map nodes label GIF sub-scenes.

Cut switches immediately; Smooth crossfades matching frames; Fade passes through black; Slide moves the incoming frame. GIF and still backgrounds use the same scene fit/framing so switching does not apply a geometric warp. An unassigned dialogue returns to the main view. The included café loops have matched still fallbacks when Reduced effects is enabled.

The café example preserves the original uploaded PNG as an asset. Its five-second GIF loops are composited from that fixed artwork with soft local eye masks from a closed-eye keyframe and a tiny candle-flame patch. Whole frames are not independently regenerated. The cake variant changes only the plate area and repeats the same animation. Normal scene effects add restrained light variation and a very small masked background sway; these remain editable. GIFs use 768×512, 12 fps and a fixed colour palette to keep portable exports within hosting limits; the original full-resolution still remains in the gallery. Source keyframes, matched plate composite, GIFs and renderer are preserved in artwork/cafe-animation and scripts/make-cafe-gif.py.

The cake view is triggered at **beat-10**, the existing cake comment, and stays assigned through the remaining café dialogues. Original still and cake still cards are available to assign to other cues. The new scene-seven background looks forward down a wet street toward fairground and ice-cream lights, with puddle masks relocated to its road. This supplies a setting for a future ice-cream branch; it does not invent that story branch.

Compatible saved projects receive these requested example updates once, with the existing recovery-copy system. Custom uploaded café or departure backgrounds are preserved. The original café file remains byte-for-byte intact; the prior visual setup is also available in Git history before version 2.15.

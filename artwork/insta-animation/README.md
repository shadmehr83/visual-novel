# Reusable animation source assets

New generated PNG originals, saved unchanged:

- `wind-leaf.png`: painterly leaf sprite used for tumbling street foliage.
- `loose-page.png`: paper texture used in the page-lift animation.
- `passing-city.png`: panoramic city painting used behind the tram window.

The existing paintings in `../insta-originals/` were used as style references and
remain unchanged. `tram-window-mask.svg` is a technical mask that retains the
window frame, foreground plant and rail while the outside city moves.

The renderer is `../../scripts/animate-insta-videos.py`; audio sources and stems
are in `../../references/audio/insta/`. The [media index](../../references/media/README.md)
includes earlier unused versions and links for downloading reusable files.

# Original paintings for the fictional Insta feed

These four new vertical paintings were generated for Stillframe's fictional feed,
using the preserved Rainy Café Conversation as a style reference. They match its
painterly charcoal, blue-grey and amber atmosphere. They do not replace any scene
background or alter Maria's portrait. Generated PNG bytes are archived unchanged.

The production script `../../scripts/make-insta-videos.py` composites restrained
camera motion, rain, steam and local lamplight into 24-second videos and synthesises
original ambience. Output MP4s and posters are in `../../public/media/insta/`.
That folder's manifest records original-painting and video checksums.

See [the feed guide](../../docs/INSTA_VIDEO_FEED.md) for controls and portability.
